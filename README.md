# Lunar Events (LunarEvents)

Серверный мод для **7 Days to Die V3.4.0 (b10)**: фазы луны меняют геймплей.
Ночь длится с 22:00 до 04:00; фаза определяется игровым днём (`day % 8`).
Ночь после полуночи относится к прошлому дню, поэтому эффект не меняется в 00:00.

## Базовые фазы

| Фаза | Эффект |
|---|---|
| 0 — полнолуние | опыт +10 % |
| 1 | скорость +10 % |
| 2 | урон +5 % |
| 3 | лут +10 % |
| 4 — новолуние | опыт −10 % |
| 5 | скорость −10 % |
| 6 | урон −20 % |
| 7 | лут −10 % |

## Особые луны

Шанс 10 % на ночь. Ролл детерминированный: зависит от сида мира и игрового дня,
поэтому перезапуск игры не меняет луну. Веса: 60 % благословение / 40 % проклятие.

| Луна | Вес | Эффект |
|---|---|---|
| Урожайная | 18 | сбор +50 % |
| Эффективная | 14 | крафт −30 % |
| Золотая | 14 | торговля +10 %, лут +20 % |
| Путешественника | 14 | топливо −30 %, стамина −20 % |
| Бедности | 12 | лут −95 %, цены +25 % |
| Лени | 12 | скорость −20 % |
| **Дикая** | 10 | стаи диких зомби рядом с игроком |
| **Фатальная** | 6 | зомби чуют игрока сквозь стены и убивают с одного удара |

Днём все баффы снимаются.

### Дикая луна

Каждые 25 секунд рядом с игроками появляются дикие (feral) зомби: 24–40 м,
по 3 за волну. Лимит — `6 + 3 × число игроков` (соло: 9). Сразу берут игрока целью.

### Фатальная луна

Каждые 2 секунды все зомби в радиусе 64 м получают ближайшего игрока целью,
в том числе сквозь стены. Любой удар зомби по игроку наносит 100 000 урона.

## Установка

Скопировать папку `LunarEvents` в `Mods` игры. Для отображения иконок и описаний
мод должен стоять и на клиенте.

## Консольные команды (F1)

```
lunarevents status
lunarevents set <harvest|craft|trade|travel|poverty|lazy|wild|fatal|none>
lunarevents clear
lunarevents spawn [1-20]
lunarevents phase <0-7|auto>
```

Алиас: `le`. Команды нужны для проверки; в обычной игре ничего вводить не требуется.

## Структура

- `LunarEvents.dll` — логика фаз, спавн «Дикой», агр и ваншот «Фатальной»;
- `Config/buffs.xml` — 16 баффов;
- `Config/Localization.csv` — названия и описания RU/EN;
- `Resources/UIAtlases/UIAtlas/` — иконки 160×160 (`ui_game_symbol_lunar_*`);
  дубль в `UIAtlases/UIAtlas/`;
- `Source/` — исходники и `build.ps1`.

## Сборка

```
powershell -File Source\build.ps1
```

Скрипт собирает `LunarEvents.dll` и копирует его в корень мода.
