# Lunar Events (LunarEvents)

Серверный мод для **7 Days to Die V3.4.0 (b10)**: фазы луны меняют геймплей.
Ночь длится с 22:00 до 04:00; фаза определяется игровым днём (`day % 8`).
Ночь после полуночи относится к прошлому дню, поэтому эффект не меняется в 00:00.
С версии 0.3.0 есть и дневные фазы — с 04:00 до 22:00.

## Базовые фазы

| Фаза | Эффект |
|---|---|
| 0 — полнолуние | опыт +10 % |
| 1 | скорость игрока +10 % |
| 2 | урон игрока +5 % |
| 3 | крит +10 %, падения опаснее |
| 4 — новолуние | опыт −10 % |
| 5 | **зомби быстрее на 10 %** (игрок не замедляется) |
| 6 | урон игрока −20 % |
| 7 | крит −10 %, падения безопаснее |

## Особые луны

Шанс 10 % на ночь. Ролл детерминированный: зависит от сида мира и игрового дня,
поэтому перезапуск игры не меняет луну. Веса: 60 % благословение / 40 % проклятие.

| Луна | Вес | Эффект |
|---|---|---|
| Урожайная | 18 | добыча ресурсов +50 % |
| Эффективная | 14 | крафт −30 % |
| Золотая | 14 | скидка 10 %, дюки +20 %, шанс лута +10 % |
| Путешественника | 14 | топливо −30 %, стамина на транспорте −20 % |
| Бедности | 12 | шанс лута до 5 %, цены +25 % |
| Лени | 12 | скорость игроков −20 % |
| **Дикая** | 10 | **все спавны зомби — минимум дикие** |
| **Фатальная** | 6 | зомби чуют игрока сквозь стены и убивают с одного удара |

Днём ночные баффы снимаются, вместо них действует дневная фаза.

## API для клиентских модов (0.4.0)

`LunarEventsApi.SpecialForNight(int seed, int nightDay)` возвращает ид особой
луны (`lunar_harvest`, `lunar_fatal`, …) или пустую строку. Ролл считается
детерминированно и не требует серверного тика, поэтому клиентский DifRUST
может на тех же ночах делать вторую луну ярче и подкрашивать её под событие.
Жёсткой зависимости нет: DifRUST ищет тип рефлексией и без него просто
показывает вторую луну в обычном спокойном оттенке.

## Дневные фазы (0.3.0)

С 04:00 до 22:00 работает дневная фаза: бафф, дебафф или нейтральный день.
Ставка на экономику и логистику: торговля, крафт, лут, транспорт, быт. День
заставляет менять план, даже если ночью вы отсиживаетесь на базе.

Пул: **9 баффов + 7 дебаффов + 2 нейтральных + 2 редких «двойных»**.
Фаза выбирается детерминированным «мешком» (shuffle-bag) на цикл из 18 дней:
каждая обычная фаза выпадает один раз за цикл, без повторов подряд,
перезапуск игры не меняет день. Редкая фаза с шансом 12% заменяет обычную.

- день 1 — нейтральный;
- день кровавой луны — «Подготовка к орде», эффектов нет;
- утро после орды — гарантированный бафф;
- не больше двух дебаффов подряд (третий меняется местами со следующим баффом).

| Фаза | Тип | Эффект |
|---|---|---|
| Благосклонность торговцев | + | покупка/продажа +15 % |
| Щедрая земля | + | добыча +20 % |
| Вдохновение мастера | + | крафт −25 % времени |
| Попутный ветер | + | топливо −25 %, скорость техники +10 % |
| Удачный день | + | шанс лута +15 %, количество +10 % |
| Лёгкая нога | + | бег/ходьба +10 % |
| Тихий шаг | + | шум −25 % |
| Сытый день | + | еда/вода −25 % |
| Закалённые руки | + | износ −20 % |
| Жадность синдиката | − | покупка −20 %, продажа −15 % |
| Вязкий воздух | − | топливо +30 % |
| Изнуряющий зной | − | еда/вода +25 % |
| Хрупкий металл | − | износ +20 % |
| Скудная земля | − | добыча −20 % |
| Шумный день | − | шум +30 % |
| Тяжёлые ноги | − | бег/ходьба −10 %, стамина +10 % |
| Спокойный / Пасмурный | 0 | без эффектов |
| День охотника | редкая | урон +15 %, шум +25 % |
| День мастера | редкая | крафт −35 %, износ +15 % |

Фаза объявляется в чате на рассвете и видна иконкой в бафф-баре.

Настройки — `lunarevents.xml` в корне мода (необязательный файл):

```xml
<LunarEvents>
  <Day enabled="true" rareChance="12" />
</LunarEvents>
```

### Дикая луна

Все зомби, которые появляются этой ночью — обычный спавн, орда, призывы —
создаются сразу дикими (feral): больше здоровья и урона. Класс меняется до
создания сущности, поэтому feral-статы применяются полностью. Если у класса
нет feral-варианта, он остаётся обычным.

### Фатальная луна

Каждые 2 секунды все зомби в радиусе 64 м получают ближайшего игрока целью,
в том числе сквозь стены. Любой удар зомби по игроку наносит 100 000 урона.

## Установка

Скопировать папку `LunarEvents` в `Mods` игры. Для отображения иконок и описаний
мод должен стоять и на клиенте.

## Админ-панель (0.4.0)

Графическая панель для тестов: только у **хоста**, чей Steam/EOS-id или имя
указан в `lunarevents.xml`. У клиентов её нет вообще.

```xml
<Admin enabled="true" key="NumPad7"
       ids="Steam_76561198287199664, 00024b296e1149fa8b2efebcf61a13f9"
       names="BlackMass" />
```

- `key` — клавиша: `NumPad7`, `NumPad9`, `F10`, `Ctrl+NumPad7`…;
- `ids` / `names` — через запятую; пустые оба = панель у любого хоста;
- `enabled="false"` — панель выключена целиком.

Что внутри: живой статус (день, ночь, фаза, особая луна, дневная фаза,
живые «дикие»), кнопки особых лун (`Дикая`, `Фатальная`, `Снять`), фазы
`0–7`/`Авто`, переключение дневных фаз и шанса редких, спавн диких (3/6/10),
перемотка времени (21:50 / 23:00 / 03:50 / 06:10), тумблер `diag` и
копирование статуса в буфер.

**Отложенный запуск.** Тумблер «Отложить»: выбранный эффект не применяется
сразу, а ждёт нужного времени суток — дневная фаза включится в 04:00,
особая луна в 22:00. Иначе авто-выбор LunarEvents перебьёт ручную фазу в
начале дня/ночи. В панели видно, что стоит в очереди, и есть «Отменить
очередь»; применяется, даже если окно закрыто.

## Консольные команды (F1)

```
lunarevents status
lunarevents set <harvest|craft|trade|travel|poverty|lazy|wild|fatal|none>
lunarevents clear
lunarevents spawn [1-20]
lunarevents phase <0-7|auto>
lunarevents day list
lunarevents day set <id|neutral|auto>
lunarevents day on|off
lunarevents stat
lunarevents parkour off|on
```

Алиас: `lunar`. Ванильный `le` — это `listentities`, он не относится к моду. Команды нужны для проверки; в обычной игре ничего вводить не требуется.

### Как тестировать ночные фазы

Ночные баффы работают только с 22:00 до 04:00. Быстрый способ:

```
settime night        ; ставит ночь (день 2, 00:00)
lunar phase 3           ; крит/падение
lunar stat              ; какие баффы висят и какой fallDamageModifier
lunar phase 5           ; зомби +10%
lunar phase 7           ; крит вниз / падения безопаснее
lunar phase auto        ; вернуть автофазу
```

`lunar stat` показывает `parkourBonus`, `fallDamageModifier` и наличие баффов
`lunar_crit_up`, `lunar_crit_down`, `lunar_speed_down`.

**Паркур 5** полностью убирает урон от падения (в `buffPlayerFallingDamage`
из скорости удара вычитается `$parkourBonus = 0.9`). Для проверки падения:

```
lunar parkour off       ; временно убрать защиту паркура (запомнит старое значение)
... прыжок с 4-6 блоков, сравнить с фазой 7 ...
lunar parkour on        ; вернуть как было
```

`lunar parkour off` действует на первого игрока (хоста) и не сохраняется после
перезахода. После теста обязательно вернуть `on`.

## Структура

- `LunarEvents.dll` — логика фаз, спавн «Дикой», агр и ваншот «Фатальной»;
- `Source/LunarDay.cs` — дневные фазы: пул, «мешок», кровавая луна;
- `Source/LunarConfig.cs` — чтение `lunarevents.xml`;
- `Config/buffs.xml` — 35 баффов (16 ночных + 1 скрытый для зомби + 18 дневных);
- `Config/Localization.csv` — названия и описания RU/EN;
- `lunarevents.xml` — настройки дневных фаз (в корне мода, не в Config);
- `Resources/UIAtlases/UIAtlas/` — иконки 160×160 (`ui_game_symbol_lunar_*`);
  дубль в `UIAtlases/UIAtlas/`;
- `Source/` — исходники и `build.ps1`.

## Сборка

```
powershell -File Source\build.ps1
```

Скрипт собирает `LunarEvents.dll` и копирует его в корень мода.
