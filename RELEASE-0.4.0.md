# LunarEvents 0.4.0 — API для клиентских модов и админ-панель

## LunarEvents 0.4.0

Два новых блока: публичный API для соседних клиентских модов и админ-панель
хоста. Фазы, веса, шансы и иконки не менялись — поведение луны прежнее.

### Установка

- **Хост / выделенный сервер:** полный архив `LunarEvents-0.4.0.zip` в
  `Mods\LunarEvents\`.
- **Клиентам:** `LunarEvents-Client-0.4.0.zip` — только `Config` и `UIAtlases`
  (иконки, названия, описания баффов). DLL не нужна: логика работает на хосте.

Нужен `0_TFP_Harmony`, игра — без EAC.

### API для клиентских модов

```csharp
string id = LunarEventsApi.SpecialForNight(seed, nightDay);
// "lunar_harvest", "lunar_fatal", ... или "" для обычной ночи
```

- `LunarEventsApi.Version = 1`.
- Ролл детерминированный: клиент считает то же, что сервер, без сетевого
  запроса и без серверного тика.
- Жёсткой зависимости нет: DifRUST 1.7.0 ищет тип рефлексией. Без
  LunarEvents вторая луна просто остаётся спокойной.
- API отдаёт только ид особой луны — никаких внутренних типов.

### Админ-панель

- Открывается **NumPad7** (клавиша настраивается), только у хоста, чей id или
  имя перечислены в `lunarevents.xml`.
- Те же действия, что у консольной команды `lunarevents`: выбрать луну,
  посмотреть текущую фазу и событие.
- Настройка:

```xml
<Admin enabled="true" key="NumPad7"
       ids="Steam_7656119..., 00024b29..."
       names="YourName" />
```

Пустые `ids` и `names` — панель у любого хоста (удобно для отладки).
`Ctrl+NumPad7` тоже поддерживается.

### Мелочи

- В лог при старте добавлена строка конфига: `admin=… key=… ids=… names=…`.
- `lunarevents.xml` помечен версией 0.4.0.

### Файлы

- `LunarEvents-0.4.0.zip` — полный мод (DLL, конфиг, иконки, исходники).
- `LunarEvents-Client-0.4.0.zip` — клиентский пакет без DLL.
